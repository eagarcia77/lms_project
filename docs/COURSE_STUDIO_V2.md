# NEXUS Course Studio V2

El estudio de autoría permite crear contenido instruccional sin depender de una licencia comercial de Microsoft Office.

## Flujo de trabajo

1. Inicie sesión en `/admin/login`.
2. Abra **Diseñador**.
3. Seleccione un curso.
4. Cree uno o más módulos.
5. Use **Añadir contenido** para crear páginas, documentos, enlaces, videos, actividades, asignaciones, discusiones o evaluaciones.
6. Guarde como borrador o publique.

## Editor nativo

El editor enriquecido permite encabezados, énfasis, listas, enlaces, imágenes, tablas y contenido HTML seguro. El contenido se almacena en la base de datos institucional y puede visualizarse antes de publicarlo.

## Google Workspace

Los accesos rápidos abren:

- Google Docs
- Google Slides
- Google Sheets
- Google Forms
- Google Drive

Después de crear el recurso, comparta el archivo con los permisos apropiados y pegue su enlace en el elemento del módulo. Para incrustar, use una URL de publicación o incorporación autorizada por Google.

## Herramientas gratuitas y abiertas

- diagrams.net para diagramas y mapas conceptuales.
- Excalidraw para pizarras y dibujos.
- GeoGebra para matemáticas interactivas.
- Mermaid Live para diagramas basados en texto.
- Lumi para crear paquetes H5P.
- Canva y YouTube Studio mediante enlaces externos.
- Recursos AR y VR mediante URLs WebXR, A-Frame o model-viewer.

## Tipos de contenido

Página, documento, presentación, hoja de cálculo, enlace, video, audio, imagen, PDF, contenido incrustado, diagrama, matemáticas, actividad interactiva, AR, VR, asignación, discusión, evaluación, rúbrica y anuncio.

## Seguridad

El HTML se filtra mediante una lista permitida. Los iframes no se guardan directamente en el editor; deben configurarse mediante el campo de URL incrustada. Las credenciales y secretos nunca deben almacenarse en el repositorio.

## Limitaciones actuales

ONLYOFFICE y Collabora Online requieren servicios adicionales, almacenamiento persistente y configuración de seguridad. No se incluyen dentro del contenedor gratuito de Render en esta fase. El editor nativo y Google Workspace cubren la creación inicial sin añadir infraestructura de pago.
