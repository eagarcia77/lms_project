# NUVEDRA Visual Course Studio v1

## Role model

- Administrators create and configure courses, assign instructors, manage enrollments, and activate courses.
- Administrators may grant themselves course-level instructor access without replacing the primary instructor.
- Instructors create and edit modules, learning content, Google links, emerging-technology activities, and assessments.
- Students view only active courses and published content, and may submit enabled assessments.

## Instructor workflow

1. Open **My courses** and select a course.
2. Create or reorder modules.
3. Open a module and choose a visual content type.
4. Add instructions, links, points, due dates, and an accessible alternative.
5. Edit existing items with the visual formatting toolbar.
6. Publish or unpublish individual items.
7. Preview the course as a student.

## Included in v1

- English-first visual interface with Spanish support.
- Local draft recovery for forms.
- Module and content ordering.
- Module and content duplication.
- Publish and unpublish controls.
- Google Docs, Slides, Sheets, and Forms shortcuts.
- H5P, simulation, AR, VR/WebXR, and 360° content types.
- Assessment response type, attempts, time limit, rubric, points, and due date.
- Accessible-alternative field for learning items.
- Responsive design, reduced-motion support, keyboard focus, and forced-color support.
